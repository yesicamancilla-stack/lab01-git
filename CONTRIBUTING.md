
# Guia de contribucion

Gracias por tu interes en colaborar con este proyecto.

## Reportar errores

Si encuentras un error:

1. Ingresa a la seccion Issues del repositorio.
2. Crea un nuevo Issue.
3. Describe el problema encontrado.
4. Explica los pasos para reproducirlo.

## Proponer mejoras

Para sugerir una mejora:

1. Revisa si existe una propuesta similar.
2. Crea un Issue explicando tu idea.
3. Describe como ayudaria al proyecto.

## Enviar cambios

1. Haz un fork del repositorio.
2. Crea una rama para tus modificaciones.
3. Realiza los cambios necesarios.
4. Guarda tus cambios mediante un commit.
5. Abre un Pull Request.

## Lista de verificacion

Antes de enviar un Pull Request, comprueba:

- [ ] El codigo funciona correctamente.
- [ ] Los archivos estan organizados.
- [ ] La documentacion esta actualizada.
- [ ] El cambio tiene una descripcion clara.
